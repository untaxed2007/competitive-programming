# Competitive Programming

A personal workspace for competitive programming notes, reusable implementations, and solutions.

## Folders

- `algorithms/`: General algorithm implementations and references, such as searching and sorting.
- `data_structures/`: Data structure implementations, such as trees, heaps, and disjoint sets.
- `math/`: Number theory, combinatorics, and other mathematical techniques.
- `graph/`: Graph algorithms, traversals, and graph-related utilities.
- `dp/`: Dynamic programming patterns and implementations.
- `strings/`: String processing algorithms and related utilities.
- `bits/`: Bit manipulation techniques and bitwise algorithms.
- `solutions/codeforces/`: Solutions to Codeforces problems.
- `solutions/codechef/`: Solutions to CodeChef problems.
- `solutions/leetcode/`: Solutions to LeetCode problems.

`template.cpp` is a basic starting point for C++ submissions. `cheatsheet.md` collects topic headings and quick-reference notes.
